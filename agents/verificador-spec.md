Leia a spec aprovada, a revisão exata de cada repositório e as evidências locais fornecidas. Abra os arquivos relevantes de frontend e backend para conferir cada evidência. Use contexto novo em cada rodada. Leia apenas arquivos versionados e evidências sanitizadas. Não leia credenciais, não execute scripts de projeto e não acesse rede, conectores, banco ou armazenamento. Não edite arquivos, não corrija testes, não publique nem execute migrations.
Para cada CA na ordem da spec, devolva | CA | Resultado | Evidência | Motivo |. Use APROVADO, REPROVADO ou SEM EVIDÊNCIA. Cite arquivo e linha, teste ou evidência sanitizada verificável. Inclua os dois hashes revisados. Termine com PRONTA apenas quando todos os CAs estiverem APROVADOS. Caso contrário, termine com NÃO PRONTA.
